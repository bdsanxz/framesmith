# ML runners reference (Sprint 23, T005)

One composition proving every Sprint 23 outcome end to end: consented
model installs, stub-driven transcription into a captions track with
word times intact, deterministic text-to-speech on an audio track,
background removal into the subject-matte slot with the inverse plate
behind it, and a pure-Rust beat grid with BPM on the reference music.
The one-command gate is
[`tools/n23-runners-proof.sh`](../../tools/n23-runners-proof.sh).

## Contents

- [`composition.kdl`](composition.kdl) — the reference composition:
  one `image` clip with the inverse plate as the backdrop, one
  `audio` clip with the synthesized voice, and one `captions` clip
  ordered behind the subject matte (`behind-subject=true` with
  `matte="bg/subject-alpha.png"`), on a 64x48, 4s, 10fps film. A
  linear `tween` sweeps the plate so the timeline is not frozen.
- [`speech.wav`](speech.wav) / [`shot.png`](shot.png) /
  [`click.wav`](click.wav) — deterministic input fixtures (stdlib
  generated): a 4s 220 Hz tone at 48 kHz mono, a 64x48 still with a
  red background and a blue subject box, and a 4s 120 BPM click
  track (seven 0.15s decayed bursts every 0.5s with leading silence).
- [`speech.transcript.json`](speech.transcript.json) /
  [`speech.transcript.srt`](speech.transcript.srt) — stub
  transcription of `speech.wav`: two cues, four words each, with
  per-word times `[0, 0.5) ... [3.5, 4)`. Expected regenerated bytes.
- [`voice.wav`](voice.wav) — stub TTS of "hello framesmith"
  (`aria`, speed 1.0). Expected regenerated bytes.
- [`bg/subject-alpha.png`](bg/subject-alpha.png) /
  [`bg/background-plate.png`](bg/background-plate.png) — stub
  background removal of `shot.png` (white subject alpha, inverse
  plate). Expected regenerated bytes.
- [`click.beats.json`](click.beats.json) — beat grid for
  `click.wav`: 120.0 BPM, eight snapped beats from 0.498s, the
  leading `[0.0, 0.5]` silence marked. Expected regenerated bytes.
- [`README.md`](README.md) — this file.

The runner artifacts above are fixtures for the gate: the proof
stages this folder, re-runs every runner with the stub engines and
requires byte-identical regeneration before consuming them in the
composition, so a fixture that drifts from the code fails the gate.

## Proof map (what the gate checks)

| Gate | Proves | How |
| --- | --- | --- |
| models + consent | list shows all 7 models; no-consent refuses naming `--yes` with nothing staged; installs verify SHA256; cached bytes equal registry bytes; re-install skips | `models list` / `models install`, local registry under a dead proxy, `cmp` |
| transcription | transcript regenerates byte-identical; word windows parse exactly; cue frames paint and differ; SRT interchange is snapshot-identical | `transcribe --to srt`, snapshots at 1.0s/3.0s vs bare plate, `src` swap |
| TTS | voice regenerates byte-identical; audio contributes to the mix; double render identical with h264+aac streams | `tts`, `master peak` in `check`, ffprobe streams |
| matte + plate | alpha/plate regenerate byte-identical; alpha covers the subject, plate matches the background; behind-subject snapshots prove cover pixels | `remove-background`, pixel checks, matte-stripped copy snapshots |
| beats | 120 BPM with snapped times and silence marked; beat file regenerates byte-identical | `beats`, beat-file parse |
| refusals | missing model, offline, low-confidence audio, unknown voice, missing engine each exit non-zero naming the fix with nothing staged | isolated caches/envs, file-absence asserts |
| doctor | health matches runner resolution | `doctor` vs `models list` state parity, `doctor --json` |
| zero network | no download URL in any log; installs verified from the local registry under a dead proxy | log census, cache/registry `cmp` |
| cargo tests | touched crates stay green | `cargo test -p ml` (21), `cargo test -p cli --test cli_n23_ml_runners` (5) |

All references are to the stub engines behind the explicit
`--engine stub` override; no model weights are downloaded and no
runner touches the network. Missing-engines refusals name the install
fix; real engines (`auto`) are never probed by this gate beyond
`doctor`.
